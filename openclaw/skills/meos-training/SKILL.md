# MeOS 훈련 분석

사용자의 러닝 훈련을 분석하고 **결과를 MeOS 에 올려** 휴대폰·PC 어디서나 볼 수 있게 한다.

## 언제 쓰나

- "오늘 훈련 어때?", "어제 러닝 봐줘", "이번 세션 분석해줘" → **분석 + 자동으로 MeOS 에 올린다**
- "MeOS 에 훈련 분석 올려줘" → 방금 한 분석을 올린다 (없으면 새로 분석해서 올린다)
- "최근 훈련 목록", "지난주 뭐 뛰었지" → 목록만 보여준다

**러닝 한 세션을 분석할 때는 언제나 이 스킬을 쓴다.** intervals.icu 를 직접 볼 수 있더라도,
분석 결과가 MeOS 에 남아야 휴대폰에서 볼 수 있기 때문이다.

## 언제 쓰지 않나 (중요)

**러닝이 아닌 질문에는 쓰지 않는다.** 이 사용자는 러닝 기록이 압도적으로 많아서 아무 질문이나
러닝으로 끌려가기 쉽다. 실제로 체형 질문("이번 주에 뭘 어떻게 조정할까")을 러닝 훈련 분석으로
받아 엉뚱하게 답한 적이 있다.

| 질문 | 쓸 것 |
|---|---|
| 체중·체지방·근육량·인바디·식단·칼로리·목표 달성 | `meos_body` · `meos_overview` 도구 (이 스킬 **아님**) |
| 근력·세트·볼륨·종목·1RM | `meos_strength` 도구 (이 스킬 **아님**) |
| 여러 주에 걸친 흐름·전반적인 컨디션 | `meos_overview` 도구 (이 스킬 **아님**) |
| **러닝 한 세션**의 페이스·심박·랩·훈련부하 | 이 스킬 |

MeOS 어시스턴트 채널로 들어온 질문에는 그 채널이 도구 안내를 따로 붙여 준다. 그걸 따른다.

분석을 말로만 해주고 끝내지 말 것. **분석했으면 올린다** — 사용자가 원하는 최종 상태는
"MeOS 훈련 상세에 코멘트가 붙어 있는 것" 이다. 목록 조회만 요청받았을 땐 올리지 않는다.

자료를 다른 경로(직접 intervals.icu 조회 등)로 이미 얻었더라도, **올리는 단계는 반드시**
`node {baseDir}/scripts/meos.mjs post <활동id>` 로 한다. 활동 id 는 `today`/`recent` 로 확인한다.

## 자료 받기

```bash
node {baseDir}/scripts/meos.mjs today
```

오늘 훈련이 없으면 가장 최근 것을 준다 (`isToday` 로 구분). 특정 훈련이면:

```bash
node {baseDir}/scripts/meos.mjs recent 10      # 목록에서 활동 id 고르기
node {baseDir}/scripts/meos.mjs get i174540791
```

돌아오는 것: 활동 요약(거리·시간·평균/최고 심박·훈련부하·심박존 시간), **랩 배열**, `lthr`,
이미 올라간 코멘트(`note`).

랩의 `type` 은 믿지 말 것 — intervals.icu 는 워밍업·쿨다운까지 `WORK` 로 준다.
**반복 세트는 페이스·심박이 뚜렷하게 높은 랩 무리**로 직접 판단한다.

## 분석 쓰기

MeOS 화면에는 이미 **규칙 기반 수치**가 나와 있다 — LTHR 초과율, 반복 편차, 드리프트,
페이스 유지, 목표존 적중률, 회복 깊이, 지난 세션 대비.

그러니 **숫자를 다시 나열하지 말고** 이런 걸 쓴다:

- 이 세션이 의도한 자극을 줬는지, 줬다면 왜 그렇게 보는지
- 걱정되는 신호 (후반 심박 급상승, 회복 부족, 페이스 붕괴 등)와 짚이는 원인
- **다음 세션 조정 제안** — 구체적으로 (반복 수, 페이스, 회복 시간)
- 최근 흐름 속에서 이번 훈련의 위치

한국어로, 3~5문단, 존댓말. 사용자는 NSM(Norwegian Singles Method) 로 훈련한다 —
역치 근처를 자주, 그러나 넘지 않는 것이 핵심이다. LTHR 초과는 실패가 아니라 **조정 신호**로 다룬다.

## 올리기

본문은 반드시 **stdin** 으로 넘긴다. 명령줄 인자로 넣으면 한국어·개행이 깨진다.

```bash
node {baseDir}/scripts/meos.mjs post i174540791 --model gpt-5.4 << 'EOF'
SubT 1km x6, 잘 소화했습니다.

반복 6개가 159→169로 완만하게 올랐는데 역치 세션에서는 정상적인 반응입니다.
...
EOF
```

성공하면 `[meos] 올렸습니다: <id> (N자)` 가 나온다. 같은 훈련에 다시 올리면 **덮어쓴다**.

올린 뒤에는 사용자에게 분석 내용을 그대로 보여주고, 마지막에 MeOS 에 올렸다고 한 줄 덧붙인다.

## 문제가 생기면

- `MEOS_NOTE_TOKEN 환경변수가 없습니다` → openclaw.json 의 `skills.entries.meos-training` 설정 확인
- `UNAUTHORIZED` → 토큰이 틀렸다. MeOS 쪽에서 재발급했는지 확인
- `활동이 없습니다` → MeOS 동기화가 아직 안 된 것. 잠시 뒤 다시 시도
